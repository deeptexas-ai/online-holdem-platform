# 德州扑克在线平台源码：C++ 实时牌局与房间服务

本仓库公开一组面向**在线德州扑克平台**的 C++ 游戏服务端组件、Tars 协议、房间/客户端消息处理代码与真实产品界面。它适合用于研究多人牌局状态机、下注消息、房间同步、私人局和俱乐部产品流程。

> 范围说明：下面将“代码可核实能力”和“截图展示的产品入口”分开描述。仓库没有公开 Docker Compose、数据库初始化脚本或性能测试报告，因此不承诺一键部署、固定并发量或完整商业交付。

## 玩家看到的产品流程

1. **登录与账户入口**：产品截图展示手机登录、邮箱登录、注册和密码找回。
2. **大厅与玩法筛选**：大厅可见经典德州、AOF、6+ 短牌、MTT、SNG，以及不同盲注、时长和人数的房间。
3. **创建私人牌局**：创建页展示玩法、盲注、60–180 分钟、2–9 人和速度设置。
4. **俱乐部体系**：用户可创建或按 ID 加入俱乐部，浏览已加入俱乐部和牌局数量。
5. **实时牌桌**：牌桌展示座位、底池、公共牌、底牌、弃牌、过牌和加注操作。
6. **个人信息**：个人中心展示 VIP、背包、成就、游戏统计、指标统计、客服和设置入口。

## 代码可核实的技术模块

| 模块 | 主要文件 | 可验证内容 |
| --- | --- | --- |
| 游戏状态机 | `process/process.cpp`、`process/process.h` | 开局、前注、庄家、发底牌、公共牌、转牌、河牌、结束等状态切换 |
| 牌桌恢复 | `gamestation.cpp` | 当前阶段、玩家状态、下注额、公共牌、底牌可见性和剩余操作时间同步 |
| 消息处理 | `message/`、`onclientmessage.*`、`onroommessage.*` | 客户端消息、房间消息、发送到单个/全部玩家和观察者 |
| 德州协议 | `protos/dzproto.tars` | 盲注、最小带入、下注动作、底池、发牌、记录、自动下注、买入和计时消息 |
| 游戏服务 | `gameserver.*`、`gameroot.*` | 房间与游戏服务通信、消息广播和游戏根对象 |
| 推送接口 | `PushServant.tars`、`PushServer.h` | 推送服务接口与服务端入口 |

## 玩法与产品边界

- **代码明确支持的德州流程**：盲注、底牌、公共牌、转牌、河牌、下注动作、底池、买入、牌局记录和结束状态。
