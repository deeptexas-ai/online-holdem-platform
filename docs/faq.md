# 常见问题

## 这是完整平台源码吗？

当前公开仓库可见内容以 C++ 游戏服务端、消息、协议和截图为主。客户端、数据库、管理后台、Docker 镜像及商业组件需以实际目录和授权说明为准。

## 如何下载？

在 [仓库首页](https://github.com/deeptexas-ai/online-holdem-platform) 点击 **Code → Download ZIP**，或使用本项目 README 中的 Git 克隆命令。

## 为什么 README 原来的 CMake 命令不能使用？

当前根目录可见 `makefile`，未显示 `CMakeLists.txt`。请使用 [构建指南](./build-guide.md)，并根据 Makefile 配置依赖。

## 是否有 Docker 镜像？

仓库根目录未显示 Dockerfile 或 Compose 文件。在发布真实镜像地址和构建文件前，不应将 Docker 命令写成已验证步骤。

## 能否直接商业运营？

不能仅凭公开仓库判断。必须确认许可证、完整组件、第三方资源、安全审计和所在地法律要求。
