Explore the platformView GitHub

Player Journey

From account entry to a live multiplayer hand

The product UI connects account access, lobby discovery, private-table configuration, clubs and a real-time table. Code evidence is described separately from screenshot-only entry points.

01 Lobby

Find a suitable table

Visible filters cover Hold'em, AOF, 6+ Short Deck, MTT and SNG, with blinds, duration and seat counts.

02 Private Play

Configure a room

Set game mode, blinds, 60–180 minute duration, 2–9 players and table speed.

03 Club

Create or join

Players can create a club, join by ID and browse joined clubs with their current table counts.

Lobby Discovery

Game modes and table state at a glance

The lobby presents Hold'em, AOF, 6+ Short Deck, MTT and SNG entry points. Each room exposes blinds, duration, seats and club association before entry.

Private Table

Build a table around the group

  • Hold'em, AOF, 6+ Short Deck, MTT and SNG entries
  • Blind, duration and 2–9 seat controls
  • Fast or standard pace settings

Club Layer

Organize recurring groups and tables

The club list shows joined clubs, identifiers, currency indicators and table counts. A separate flow allows club creation or joining by ID.
